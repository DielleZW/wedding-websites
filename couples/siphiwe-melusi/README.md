File Purposes

index.html — Loads the wedding website using the shared master files.

config.js — Contains the couple’s wedding details, venues, accommodation, RSVP, travel information and FAQs.

theme.css — Controls the enchanted-garden colours, typography and styling.

images/ — Stores the couple’s artwork, photographs and social media preview.

Shared Master Files

The website uses the following files from the main repository:

* /styles.css
* /script.js

Do not copy or replace these master files inside the couple’s folder.

Design Direction

Enchanted garden, romantic florals, butterflies, golden sunlight, blush pink, lilac, sage green and Victoria Falls scenery.

Updating the Website

Edit config.js to change wedding information.

Edit theme.css to adjust the appearance.

Upload new images into the images folder and reference their filenames in config.js.

Commit all changes to the main branch to publish through GitHub Pages.
